\section*{1. Project Overview}
This project develops a reproducible, large-scale time-series foundation model (TSFM) utilizing a masked latent reconstruction objective. The proposed architecture integrates Reversible Instance Normalization (RevIN), convolutional patch tokenization, a bidirectional Transformer encoder, and an MLP reconstruction head. Unlike existing decoder-only models (e.g., TimesFM) that rely on massive internet-scale observational data, this project addresses data scarcity by introducing a fallback mechanism to feature-bootstrap synthesis, leveraging 44 feature tables to generate synthetic temporal data for pretraining. We conducted rigorous complexity analyses and multi-seed ablations across mask ratios and patch lengths to isolate optimal compute-efficient configurations.

% -----------------------------------------------------------
% 2. HPC Utilization
% -----------------------------------------------------------
\section*{2. High-Performance Computing (HPC) Utilization}
High-Performance Computing (HPC) resources were pivotal to managing the heavy computational requirements of training large-scale transformer models on extensive time-series datasets. The HPC cluster facilitated:
\begin{itemize}
    \item \textbf{Parallel Multi-Seed Ablations:} Extensive seed-stratified ablations across configurations were executed simultaneously on multiple GPU nodes to quantify uncertainty and prevent misleading conclusions from deterministic single-seed runs.
    \item \textbf{Large-Scale Pretraining:} The compute environment supported deep training horizons (over 2.11M steps, 62 epochs), enabling detailed late-checkpoint auditing and stability analysis.
    \item \textbf{Throughput Optimization:} By utilizing HPC profiling, we empirically validated attention memory scaling ($\mathcal{O}(BN^2d)$) and epoch runtimes. This confirmed that a patch length of $P=32$ provides the optimal balance of representational capacity and runtime efficiency.
\end{itemize}

% -----------------------------------------------------------
% 3. Verified Results & Downstream Performance
% -----------------------------------------------------------
\section*{3. Verified Results and Downstream Performance}
The project successfully linked pretraining design choices to downstream forecasting performance. Key verified findings include:
\begin{itemize}
    \item \textbf{Configuration Superiority:} Multi-seed evaluations confirmed that patch length $P=32$ outperforms $P=16$ and $P=8$ in both masked reconstruction quality and runtime efficiency under a fixed step budget.
    \item \textbf{Checkpoint Stability:} The optimal masked Mean Squared Error (MSE) of 0.3304 was achieved at step 2.04M, with a minimal 2.04\% drift by the final checkpoint at step 2.11M, proving that validation-based checkpoint selection strongly outperforms recency-based selection.
    \item \textbf{Transfer Learning Efficacy:} The pretrained TSFM model transferred robustly to downstream tasks, outperforming from-scratch baselines on 3 out of 4 tested datasets (Metro, Environmental Sensor Telemetry, and ETTh1).
    \item \textbf{State-of-the-Art Benchmark Comparison:} In direct evaluation against Google's TimesFM, our initialized encoder model achieved \textbf{Rank 1} overall. It yielded a \textbf{33\% lower mean MSE}, winning 5 out of 7 standard forecasting benchmark datasets (ETTh1, ETTh2, Electricity, Traffic, and Weather).
\end{itemize}
